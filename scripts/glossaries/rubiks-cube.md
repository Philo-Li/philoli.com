This is a speedcubing (Rubik's Cube) article. Use the vocabulary the target language's cubing community actually uses, not dictionary words. Look at how speedcubing tutorials and forums in the target language phrase things.

Meaning-critical:
- "sub-30", "进入 30 秒", "30 秒以内", "sub-20", "进 15 秒" all mean UNDER that many seconds (a time below 30.00 s). Never render as "the 30-second range" / "30-something seconds" (e.g. Japanese 「30秒台」 is WRONG; write 「30秒を切る」/「sub-30」).
- 公式 = algorithm, in the speedcubing sense (a memorized move sequence). Use the community term: English "algorithm", Japanese 「手順」, Korean "공식" or "알고리즘", German "Algorithmus", French "algorithme", Spanish "algoritmo", Traditional Chinese 「公式」. Never "formula". When 公式 means "official" (公式比赛/官方), that is a different word.
- 复原 = solve (the cube). 打乱 = scramble. 速拧 = speedcubing / speedsolving. 单手 = one-handed (OH). 盲拧 = blindfolded.
- 魔方 = Rubik's Cube / the cube (Traditional Chinese 「魔術方塊」, Japanese 「ルービックキューブ」 then 「キューブ」, Korean "큐브").
- 桥式 / Roux 桥式 = the Roux method. Do not translate 桥 as "bridge" in the method name. 左桥 / 第一桥 = First Block (FB); 右桥 / 第二桥 = Second Block (SB). Use the community's FB/SB terms (e.g. German "erster/zweiter Block", French "premier/second bloc", Japanese 「左ブロック/右ブロック」).
- 棱块 = edge (piece); 角块 = corner; 中心块 = center; 顶层 = top layer / U layer (in CFOP context "last layer"); 一组色块 / 角棱对 = a corner-edge pair.
- 坏棱 / 好棱 = misoriented edge / oriented edge (EO = edge orientation). Don't say "bad/good edge" literally if the community has a better term (e.g. Japanese 「向きの違うエッジ」, German "falsch orientierte Kante").
- 慢拧 = slow solving / slow turning: deliberately slow, untimed practice. 预判 = look-ahead (many languages keep the English "look-ahead"). 手法 / 指法 = finger tricks.
- 转魔方 / 翻转魔方 (when told not to do it) = cube rotations, i.e. re-gripping and turning the whole cube — not turning a face.
- Ao5 / Ao12 / Ao50 / Ao100 = average of 5/12/50/100 solves; keep "Ao100" etc. as written. PB = personal best.
- Keep these acronyms unchanged: CFOP, F2L, OLL, PLL, CMLL, LSE, EO, UL/UR, WCA, M-slice, U-layer.
- Move notation is sacred: tokens like R, R', R2, U, U', L', M, M', M2, r, F', and sequences such as R U' L' U R' U' L U, M' U M, M2 U, F (R U R' U') F' must be copied exactly, character for character, including spaces and apostrophes.
- Jessica Fridrich: spell her name the way the target cubing community does (Japanese 「ジェシカ・フリドリッヒ」; most languages keep "Jessica Fridrich"). Gilles Roux stays "Gilles Roux". Sean Patrick Villanueva stays as is.
- 打乱 = scramble: Spanish "mezclar" (never "desarmar", which means taking the cube apart), French "mélanger", German "verdrehen/scramblen".
- 单手 = one-handed solving (OH): Korean "한 손(OH)" (never "외팔"), Japanese 「片手」, Spanish "a una mano".
- Korean: 顶层 = "윗면", 复原 = "솔브/맞추기" (not "복원"), 预判 = "룩어헤드", 慢拧 = "슬로우 솔빙". Japanese: 块 (a piece) = 「パーツ」, not 「ブロック」(reserve ブロック for the 1×2×3 blocks).
- 练什么 / 卡在哪 headings are advice to the reader: render as "What to practice" / "Where you get stuck" in second person or neutral form, never first person.
- 数字取证 = digital forensics (the research field), e.g. Spanish "informática forense".
